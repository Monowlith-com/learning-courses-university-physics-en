## Overview

This course contains 323 lessons in 43 modules. Study in sequence or use the materials for reference, revision and further study. They do not replace formal education or an accredited qualification.

## Contents

**Web reader:** Open `index.html` or the course link. Features include search, lesson navigation, reading progress, favorites, bookmarks, notes, adjustable font size and light/dark mode. The complete offline edition works without a server after extraction. No registration; reading data stays in the browser and can be exported, imported or deleted per course. All local Learning Courses data, including shared settings, can also be deleted.

**Markdown documents:** Individual documents in the subject repositories’ `master/` folders have extensive YAML frontmatter for automatic or manual categorization and ordering.

| Field | Meaning |
|---|---|
| `document_id` | Unique document identifier across courses |
| `series_id` | ID of the first course document |
| `series_part` | Consecutive position starting at 1 |
| `document_version` | Document version |
| `language`, `study_level` | Language and education level |
| `categories`, `keywords` | Categories and keywords |
| `author`, `license` | Attribution and license |
| `website`, `github` | Website and subject repository |

# University – Physics – Sources {#quellenverzeichnis}

This index covers **329 distinct external web addresses** cited in all **323 lesson drafts**. Each URL appears once, with direct links to the lessons that cite it. Source labels were normalized against the source standard; prior access evidence comes from lesson references or the original URL review queue. A URL alone does not establish support for every claim; the relevant passages in the original sources remain decisive.

## Scope and usage {#S1}

Grouping follows the module of first occurrence; URLs reused in other modules are not duplicated. Access dates are consolidated by exact URL; missing access evidence is documented in the QA report. Bibliographic references without a web address remain in their original lessons where present. External links require an internet connection; the course is designed for offline use in its reader.
